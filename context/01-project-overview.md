# Todowe

## Overview

Todowe (pronounced to-do-we) is a collaborative daily task management web app for professionals who need to plan, track, and deliver work alongside a team. The name fuses today, to-do, and we — the belief that great work is rarely done alone. It launches as a free Progressive Web App (PWA) hosted at todowe.vercel.app — no App Store, no installation, just a shared URL. Users sign in, see a time-aware greeting and their day's agenda, create and assign tasks, track progress by project, receive layered notifications, and get an honest AI-powered summary of how their week is going. The canonical design reference is the React prototype todowe-v21.jsx — every UI decision in this codebase traces back to it.

## Goals

1. A signed-in user can view, create, edit, and delete tasks organised by day on a scrollable calendar strip.
2. Users can assign tasks to collaborators, who see the task and receive a notification when added.
3. Every task can belong to a project — the dashboard tracks project completion across all tasks.
4. Users receive three types of notifications: collaboration alerts, reminder alerts (with custom timing), and smart nudges generated by the app.
5. The dashboard shows a smart weekly summary message based on the user's actual completion rate.
6. The app works identically in dark mode and light mode, switchable at any time including on the login screen.

## Core User Flow

1. User opens todowe.vercel.app and signs in with email and password.
2. App greets user by name based on time of day — Good morning, Good afternoon, Good evening.
3. User lands on the Tasks screen showing the current month's day strip and today's task timeline.
4. User scrolls the day strip or navigates months to select a date.
5. User taps the + button to add a task — sets title, category, status, start/end time, project, assignees, and reminders.
6. Task appears on the timeline in the correct time slot with the status badge, avatar notch, and progress bar.
7. Collaborators assigned to the task receive a notification in their notification centre.
8. User taps the avatar in the header to open the profile sheet — views account stats or reads notifications.
9. User taps a notification — the related task opens in the edit sheet. The notification moves to Cleared.
10. User switches to Dashboard to see the smart message, status grid, project tracker, and upcoming tasks.

## Features

### Authentication & Profile
- Email and password sign-in with session persistence
- Time-aware greeting on entry: Good morning / Good afternoon / Good evening
- Profile sheet with two tabs: Account and Notifications
- Account tab: name, email, member since, task count, active projects, completion rate, personalised status message
- Sign out from the profile sheet
- Theme toggle accessible from header and login screen

### Tasks & Calendar
- Horizontal swipeable day strip showing all days of the current month
- Month navigation with left/right arrows — navigate to any past or future month
- Task dot indicators on days that have tasks
- Five task statuses: Todo, Pending, Running, Completed, Rejected — each with a distinct colour
- Four categories: Client project, Company task, Personal, Family task — each with a diamond icon
- Tasks placed in hourly time blocks on a dashed vertical timeline
- Kebab menu (⋮) on each card: Edit task and Delete

### Add & Edit Task
- Full form: title, category, status, start time, end time, project selector, people selector, reminder picker
- Edit form is identical to Add form but pre-filled with all existing task data
- People selector: tap avatars to assign/unassign, add new person by email address
- Project selector: choose existing project or create a new one inline
- Multi-reminder picker: preset options (10 min, 30 min, 1 hr, 3 hrs, 1 day) plus a custom input (number + minutes/hours/days unit)
- Active reminders shown as tagged pills with individual remove buttons

### Projects
- Projects created inline during task creation
- Each project has a dark theme colour and a light theme colour (no washed-out text)
- Dashboard project tracker: name, progress bar, done/total count, percentage

### Notifications — Three Types
- Type 1 Collaboration: assigned to task, status changed — triggered by other people's actions
- Type 2 Reminders: set per task, multiple per task, custom timing — fire before task start time
- Type 3 Smart Nudges: overdue tasks (passed end time, still not complete), stalled tasks (Running but low progress)
- Notification centre inside profile sheet — Inbox tab and Cleared tab
- Tap notification to open related task and simultaneously move notification to Cleared
- Clear single, Clear all, Delete single, Delete all permanently

### Dashboard
- Smart weekly message: three levels based on completion rate (fire / encouragement / honest nudge)
- Status grid: count cards for all five statuses
- Completion breakdown: progress bars per status as percentage of total
- Project tracker: each project with name, progress bar, done/total, percentage
- Up Next: list of upcoming incomplete tasks across all days

### Theme
- Dark mode: navy backgrounds, lime green accent, vibrant neon status colours
- Light mode: white surfaces, warm grey backgrounds, deep accessible accent colours
- All project colours resolve via projColor() — different hex per theme

## Scope

### In Scope
- Email/password authentication via Supabase Auth
- Full task CRUD: create, read, update, delete
- Five task statuses with colour-coded cards
- Calendar day strip with month navigation
- Project creation, assignment, and dashboard tracking
- People management: existing assignees and add-by-email
- Three notification types: collaboration, reminders, smart nudges
- Notification centre: inbox, cleared, tap-to-open task, clear/delete actions
- Multi-reminder picker including custom time input
- Dark and light theme with instant switching
- PWA: installable to home screen, offline caching, web push notifications
- Deployed to Vercel free tier at todowe.vercel.app
- OpenAI GPT-4o-mini for smart dashboard message generation
- Supabase for auth, database, and real-time collaboration events

### Out Of Scope
- Native iOS or Android app builds (defer to after PWA is proven)
- Paid subscription or billing tiers
- File attachments on tasks
- Recurring tasks
- Subtasks or checklists
- Admin or team management roles beyond owner/collaborator
- Custom domain (todowe.com) — deferred until public launch
- App Store or Google Play submission — deferred

## Success Criteria

1. A signed-in user can create, edit, delete, and view tasks on any day past or future.
2. Two users can be assigned to the same task and both see it on their timeline.
3. When User A assigns User B to a task, User B receives a collaboration notification.
4. Tapping a notification opens the related task and clears the notification simultaneously.
5. Setting a reminder on a task creates a web push notification at the correct time.
6. The dashboard smart message reflects the user's actual completion rate for the current week.
7. The app installs to the home screen on iPhone and Android and functions as a standalone PWA.
8. The entire app runs at $0 cost during development and early user testing.
